# Competitors

Reference points for MINUTEMAN, a DIY aluminum **shell**. Every competitor below sells a finished or
near-finished camper, so the comparisons are about construction, weight class, and what an empty
shell costs, not about features MINUTEMAN deliberately leaves out.

All figures are as published by the cited source on the access date. They vary by model year and
options, so treat them as order-of-magnitude. **Accessed 2026-10-01 unless noted.**
