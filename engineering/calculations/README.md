# Calculations

Empty at v0.1: **nothing has been calculated.**

An assumption in `engineering/assumptions.md` may carry status `CALCULATED` only if its Reference column
cites a file in this folder, and `scripts_code/validate_model.py` fails the build otherwise.

Each calculation file states: load case, inputs (with their own statuses), method and reference
(e.g., Aluminum Design Manual section), HAZ allowables for welded joints, result, margin, and reviewer.
